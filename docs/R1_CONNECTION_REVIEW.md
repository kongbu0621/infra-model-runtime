## 实际缺陷与修复

外层 SQLite 连接在关闭时抛出 KeyboardInterrupt / SystemExit，旧代码会把它们转换为普通 STORAGE_ERROR。即使提交状态分类仍正确，上层捕获普通异常后也可能继续运行，失去原停止信号；这与合同约定的中断向上传播不一致。

现在没有本次主错误时，连接清理中的停止信号保持原类型、原对象向上传播。普通关闭错误继续返回 STORAGE_ERROR：已知提交成功保持 committed，读取保持 not_applicable。已有主错误或主中断时，次生关闭中断仍不覆盖它。

中断本身不能证明操作未提交，也不携带伪造的成功回执。调用方须按原身份查询或幂等重放获准操作；发放已经提交但令牌未返回时，后续仍为 ALREADY_ISSUED，不能重建令牌或盲目重发。关闭在真正执行前失败时，不保证连接已关闭；测试夹具最终清理资源不计作产品成功清理。
