## 已复现问题与修复

旧回显检查依赖完整严格 JSON 解析。响应截断、重复 key、非法 UTF-8、尾随内容、超深或超节点时，解析失败会跳过转义凭据检查；嵌入的损坏 JSON 和普通诊断文本也会漏检。旧源码及原 `c720608` 安装均能将这些响应交给持久层；合成端到端检查实际读回了含可还原凭据的原响应。

修复在捕获交付前检查明文及**最多两层 JSON ASCII 转义**，覆盖提供方封装及一个嵌入编码；不要求整个响应能解析。每轮扫描的输入均受响应字节上限约束，转换只缩短或保持长度，不递归展开。只扫描副本：未命中的响应仍返回准确原始 bytes，不修改业务内容或放宽协议校验。

命中后丢弃整段捕获，保留 HTTP 状态/发送事实并将 complete 标为 false。原调用保持 UNKNOWN，预留及执行占用保持；这不证明远端失败、未执行或免费，恢复不能新发请求。该检查限上述明文与转义形式，不是任意编码秘密识别；多于两层编码、其他编码方式不在本轮识别声明内。修复不回写旧捕获，也未扫描真实历史数据。

| 检查 | 范围 |
